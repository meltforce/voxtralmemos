🎙️ **Voxtral Memos — voice memo app built on Voxtral**

Hey! I built a voice memo app for iPhone that uses Voxtral for transcription and Mistral models for summarization.

The idea is simple — record a thought, get a transcript back, then optionally run it through a prompt template (summary, to-do list, journal entry, or your own custom format).

A few things that were important to me:
🔑 **BYOK** — you use your own Mistral API key, no middleman server
🔒 **Privacy-first** — no accounts, no analytics, no tracking, zero third-party SDKs
🌍 **Multilingual** — 13+ languages with auto-detection
📖 **Open source** — MIT licensed, full source on GitHub
🆓 **Free** — no ads, no subscriptions, no hidden costs

A 5-minute transcription costs about $0.01 — so practically nothing to run.
